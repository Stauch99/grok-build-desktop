# UI 评审 CheckList — Grok Build Desktop

> 评审对象：2026-08-30 全量截图（`docs/ui-audit/2026-08-30/`，38 张）
> 评审维度：交互体验 / 产品功能 / 操作逻辑 / 用户习惯 / 视觉审美
> 条目数：50 · 优先级：P0（必须改）/ P1（应该改）/ P2（可以改）
>
> 每条标注了对应的截图，便于对照。所有建议均指向截图中真实存在的界面元素。

---

## P0 — 必须改（影响核心体验 / 有明显断裂）

### 输入区（Composer）

- [ ] **P0-1 输入区下方控件悬浮、无基线对齐** · `36-mode-menu.png`
  底部工具栏（`始终批准 / grok-4.5 / 深入`）漂浮在文本框下方、左右各空约 300px，与发送键/`+` 不构成同一行。
  ➜ 改为文本框内嵌工具栏：`+` 居左、模式/模型/力度居中、发送居右，统一基线与行高。

- [ ] **P0-2 模式选中值无持久可见反馈** · `36-mode-menu.png`
  选完"深入"后输入区没有当前模式的常驻标记，切完即忘。
  ➜ 在发送键旁或状态栏放一个小的当前模式徽章（如 `深入 ·`），hover 可切。

- [ ] **P0-3 "始终批准"指示器像调试残留** · `38-sidebar-collapsed.png`
  输入区左上角红色斜体小字，颜色突兀、不可点击、无选中态。
  ➜ 提升为核心模式指示器：可点击、有选中态样式，并与 P0-2 的徽章合并。

### 信息架构 / 重复入口

- [ ] **P0-4 "会话总览"与"Dashboard"语义重叠** · `22-overlay-session-dashboard.png` vs `02-thread-dashboard-progress.png`
  右侧栏 `Dashboard` 标签与 `⌘K` 的"会话总览"覆盖层都在"看概览"，用户不知该用哪个。
  ➜ 分工：右侧栏做"当前会话实时状态"，`⌘K` 覆盖层做"跨会话浏览/跳转"。

- [ ] **P0-5 三个"工作区选择器"并存** · `37-workspace-filter.png` / 头部 `工作目录` / 状态栏 `70_Writing Projects ∨`
  同一意图三个名称、三个位置、三种行为。
  ➜ 收敛为一个权威入口，其余改只读显示或快捷跳转。

### 右侧栏 / Git

- [ ] **P0-6 Git 面板并存两个不相关子面板** · `05-rail-git.png`
  目录树 + 提交记录 + 改动文件混排，且每文件都带一个"在访达中打开"按钮，反复挤占空间。
  ➜ "在访达中打开"折叠为单行 hover 操作或右键项；`+worktree` 提升到 Git 主区。

- [ ] **P0-7 顶部工具栏操作与右侧栏标签重复** · `02-thread-dashboard-progress.png`
  `复制全部对话 / 会话操作 / 打开 Git` 与 `Git` 标签重复，归宿不清。
  ➜ 合并进统一的会话操作菜单。

### 视觉 / 层级 / 状态

- [ ] **P0-8 全应用无强调色、无视觉层级** · 全图
  统一浅灰背景 + 白色卡片，无任何强调色，卡片无边界感。
  ➜ 按项目的 `design-quality.md`：给"模式指示器 / 用量警告 / 当前会话"一套统一的语义强调色。

- [ ] **P0-9 用量（周用量 59%）用最弱视觉呈现** · 所有图侧栏底部
  预算这类最关键信息用一条细灰进度条。
  ➜ 做成显眼用量指示：接近上限时颜色渐深/渐橙，并数值放大。

- [ ] **P0-10 头部路径/标题/右侧栏标签名称撞车** · `10-sidebar-project-expanded.png`
  `proma-research →` + 会话名 + 右上角"未命名会话" + Dashboard 标签，层层叠加且都无层次。
  ➜ 只保留一处标题，面包屑与标签做视觉降权。

- [ ] **P0-11 会话运行中无"进行中"状态提示** · `02-thread-dashboard-progress.png`
  推理进行时（`TTFT —`）全 app 无明显的 running 状态，无法定位哪个会话在跑。
  ➜ 全局/行级加 running 指示（旋转图标 + 会话标题旁标记）。

## P1 — 应该改（影响效率 / 一致性 / 体验质量）

### 侧栏

- [ ] **P1-1 展开的项目下缩进层级错乱** · `10-sidebar-project-expanded.png`
  `grok_build_desktop` 下 "`Find design skills, syml`" 与标题平齐但缩进不同，像误粘贴文本。
  ➜ 修复树形缩进，统一会话条目内边距。

- [ ] **P1-2 项目名与"项目操作"箭头间距 200px** · 所有侧栏图
  名字在 x=8，箭头在 x=215，中间大段空白。
  ➜ 整行 hover 高亮 + 操作贴右缘，不再固定远距。

- [ ] **P1-3 "独立对话"扁平文件名列表无时间/分组** · `01-main.png`
  20+ 条纯文件名，无日期、无排序、无分组，扫视困难。
  ➜ 加"今天/本周/更早"时间分组。

- [ ] **P1-4 分组标题不可折叠、空分组仍占位** · 所有侧栏图
  "置顶/项目/独立对话"标题常驻，空分组也占一行。
  ➜ 分组标题可折叠，空分组自动隐藏。

- [ ] **P1-5 侧栏折叠态信号弱、无方向提示** · `38-sidebar-collapsed.png`
  折叠后只剩一条竖线 + 三图标，看不出可交互、无 tooltip。
  ➜ 加 tooltip（"展开侧栏"），保留当前项目/会话缩略标记。

- [ ] **P1-6 会话列表无 hover 态、无法就地管理** · `01-main.png`
  会话行只有点击进入一种行为，无重命名/归档/删除。
  ➜ 加 hover 底色 + 行内更多操作菜单。

- [ ] **P1-7 "独立对话"无法拖入项目分组** · `01-main.png`
  20+ 条独立对话无法归类整理。
  ➜ 支持拖放：独立对话拉进"项目"分组。

### 输入区 / 状态栏

- [ ] **P1-8 模式切换有快捷键提示，其他控件没有** · `36-mode-menu.png`
  只有"切换模式(Shift+Tab)"带快捷键。
  ➜ 统一：给所有可切换控件加快捷键，或统一走 tooltip。

- [ ] **P1-9 状态栏指标无分组、无单位** · `01-main.png`
  `TTFT — · — tok/s · — tok` 三个不同量纲的指标横排。
  ➜ 分组加标签：`首字 2.1s · 速率 45 tok/s · 已用 12k`。

- [ ] **P1-10 无撤销/恢复能力** · `11-project-menu.png` / `12-session-menu.png`
  取消置顶 / 删除项目等操作无 undo，无危险操作确认。
  ➜ 加 undo 或非模态确认（如延迟撤销 toaster）。

### 设置 / 模态

- [ ] **P1-11 设置「总览」是一长条孤立文本** · `15-settings-overview.png`
  `CLI / 登录 / inspect / MCP / Agent` 平铺，像调试面板。
  ➜ 拆成卡片/分组，每项带标题与说明。

- [ ] **P1-12 模态缺少遮罩、对比不足** · 各覆盖层
  前景内容与后台会话文字混淆，无 scrim。
  ➜ 加明确操作遮罩层。

- [ ] **P1-13 命令面板快捷键提示低对比、非 macOS 键位习惯** · `21-command-palette.png`
  底部 `shift 打开 / 关闭 / 选择 / 删除 / 跳转` 用弱文本排在最底。
  ➜ 用键帽样式 `kbd` 徽章，遵循 macOS（⇧）记法。

- [ ] **P1-14 设置页「用量」数值无单位/上下文** · `19-settings-usage.png`
  `$16.4.654`、`531.07%` 等数字无单位、语义不明、比例误导。
  ➜ 统一数字格式，加单位与"上次查询/说明"。

- [ ] **P1-15 模态关闭 `X` 位置不统一** · 各模态
  设置页与覆盖层的 `X` 键位不一致，`Esc` 行为未知。
  ➜ 统一右上角 `X` + 全局 `Esc`。

### 视觉细节

- [ ] **P1-16 图标无 tooltip / 无辅助文字** · `38-sidebar-collapsed.png` / `01-main.png`
  折叠态三图标 + 左上角设置图标为低频功能，无 tooltip 无法识别。
  ➜ 关键图标标配 aria-label + tooltip。
