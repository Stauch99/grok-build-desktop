# Security

Please **do not** open a public issue for a vulnerability that can leak credentials, execute unexpected RPC, or read blocked paths (`~/.ssh`, `auth.json`, and the rest of the asset-protocol deny list).

Report privately via [GitHub Security Advisories](https://github.com/Stauch99/grok-build-desktop/security/advisories/new).

Include:

- Affected version / commit
- What you ran (OS, which ACP CLI)
- Reproduction, impact, and whether tokens or workspace files were exposed

We will acknowledge the report and work a fix before any disclosure.
