# REVIEW · Grok Build Desktop

表面：产品界面（本机 ACP 客户端）。`rule/surface-split`

对照：`src/` 当前实现；`_knowledge_base/design-agent-desktop-ux-20260814.md` 已定三栏。`design/` 此前无产物。用户要求审计现有 UI，本轮跳过 FEATURES / PRD / 原型 / DESIGN / ui.html。`rule/gap-tagged`

假设：不换 Baseline 色板，不换对话区 Source Serif 4。P2 空壳（loop 中心、手动 compact、远程/工作流对话框、侧栏终端与提交条）已从桌面拿掉，斜杠仍直通 CLI。`rule/scope-cut`

查过：侧栏、对话列、作曲栏芯片、空会话、设置、扩展中心、ExtraOverlay、原右侧「任务与文件」三 tab、命令面板、二次确认、空/错文案、`--faint` 对比。P1 已落地统一「审阅」栏。

零发现不成立。下面 8 条按用户影响排。第 1 条是结构，标成退回原型，本轮不改信息架构。

---

## 1. 右侧面板一屏多职 — 退回原型

- **位置：** `App.tsx` 浮层 `.float-card`（任务 / 本次改动 / 上下文）。任务 tab 叠：进度、文件树、产物、终端、书签。改动 tab 叠：diff、Git 历史、请 agent 提交。上下文叠：计划文件、沙盒、LSP、许可、溢出。
- **规则：** `rule/review-not-redesign`（结构问题退回原型）。既定 IA 是进度 / 工作区 / 上下文三职，不是管理抽屉。
- **原用户后果：** 旧「任务与文件」浮层无法扫出 agent 正在干什么；该问题已由 P1 统一审阅栏解决。
- **最小改法（原型阶段定，不在本审查落地）：** 无数据的节卸载，不留标题。默认只露本轮进度 + 本轮文件。Git / 提交只出现在「本次改动」且仓库有记录时。终端、书签、许可全文不要进这个 300px 浮层。

## 2. 一个动作开一张大对话框

- **位置：** `ExtraOverlay.tsx`：工作流、远程；循环任务在无日志时几乎只有三个按钮。
- **规则：** `rule/control-fits`
- **用户后果：** 对话被 680px 空对话框盖住。用户要的是插入 `/workflows` 或复制 `grok agent serve`。
- **最小改法：** 这些入口走命令面板或直接写入作曲栏。`ExtraOverlay` 只留给真正有列表的页（图片、会话总览、记忆、用量）。

## 3. 空态只说「没有」

- **位置：** 进度「暂无」；`DashboardPanel` / `AgentsPage`「没有」；`FileTree`「没有文件」；`TokenChart`「还没有用量」；`ImagineGallery`「还没有产物」（按钮在，句子仍不点名对象）。
- **规则：** `rule/empty-has-next`
- **用户后果：** 不知道缺的是什么、下一步点哪。扩展中心空态已经有下一步，浮层没有对齐。
- **最小改法：** 空组不渲染（Dashboard 某一档为空就不要「等你 / 没有」）。文件树空：点名工作区 +「在访达打开」。用量空：点名 token 历史，不要再解释计价。进度空：卸掉整节。

## 4. 失败时摊 CLI 日志

- **位置：** `ExtensionsHub` `resultNote` 把 stderr 写进 `set-note`；市场空态把「没有源」和「刷新失败」合成一句；删除/卸载第一次点击只在 note 里写「再点一次确认」。
- **规则：** `rule/error-has-fix`
- **用户后果：** 加 MCP、装插件失败时看到一截终端输出，没有「发生了什么 / 怎么修」。
- **最小改法：** 一行人话（没写上 / 目录未信任 / 命令不存在）+ 一个动作（重试、打开 config、信任此文件夹）。完整日志留在已有的「命令日志」折叠里。市场空和刷新失败分成两种空态。

## 5. 分组标题看不清

- **位置：** `.hub-body h3`、`.float-card h3`、`.health-list .set-row label`、`.settings .hint` 使用 `--faint` `#ababab`（浅色）/ `#666`（深色），字号 11px。
- **规则：** 覆盖缺口（产品轨要求正文对背景 ≥ 4.5:1；规则表无对比 ID）
- **用户后果：** 「技能 / Git / 许可 / MCP」这些分组在扫视时消失，界面像没结构。
- **最小改法：** 分组标题改 `--muted`（`#5c5c5c` / `#b3b3b3`）。`--faint` 只给 placeholder 和装饰分隔。不换色板，不改字号阶。

## 6. 破坏性按钮不像破坏性动作

- **位置：** 扩展中心 MCP「删除」、插件「卸载」；`tapDanger` + `hub.confirmAgain`（「再点一次确认」）。
- **规则：** `rule/destructive-names`
- **用户后果：** 按钮始终写「删除」。确认写在别处。第二次误点会真删。
- **最小改法：** 按钮写成「删除 {name}」「卸载 {name}」。武装后同一按钮改成「再点一次以删除 {name}」。不要用「确认」。

## 7. 设置仍是卡片，扩展还开了第二套开关

- **位置：** `Settings.tsx` 各 tab `.set-block`；扩展 tab 里 MCP 开关列表与扩展中心重复。
- **规则：** `rule/control-fits`；产品界面反模式「卡片套卡片代替列表」（覆盖缺口）
- **用户后果：** MCP 开关有两处，状态可能看岔。设置看起来仍是上一轮被骂的卡片农场，扩展中心已经改成细线行。
- **最小改法：** 设置 · 扩展只留跳转到扩展中心。设置分组改成与会话列表相同的 row，去掉套叠的内层卡片。外观、对话、关于仍在设置，不搬信息架构。

## 8. 命令面板和浮层不是同一套名字

- **位置：** `App.tsx` 命令面板：`Dashboard`、`Imagine 产物`、`Agents / Personas`、`远程遥控`。`ExtraOverlay` 标题已是：会话总览、图片、代理、远程。
- **规则：** `rule/named-objects`
- **用户后果：** ⌘K 搜英文，打开后是中文标题，像两个产品。
- **最小改法：** 面板条目、斜杠 hint、浮层标题用同一组词：新对话、扩展中心、会话总览、图片、代理、记忆、用量、远程。
